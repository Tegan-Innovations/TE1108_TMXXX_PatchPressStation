# v1.0.0-rc.3 — Engineering handover

Pre-release for continued bug fixing and supervised pre-FAT validation.

## RC1 to RC2 development actions

RC1 is the published `ReleaseCandidate` tag at `e91e984` (release title `v1.0.0-rc.1`). No RC2 tag or published release exists in the repository at publication time. For this summary, `d3ec8de` (Prepare Vision and HMI improvements for next release candidate) is used as the candidate RC2 checkpoint; this is an explicit documentation reference, not a newly created RC2 release.

The source changes between those checkpoints include:

- Added the manual Vision image-positioning workflow, including preparation, capture, release and per-nest PBUP reference tracking, with camera recovery and operator feedback.
- Updated Vision manual/settings pages, camera diagnostics and status presentation.
- Updated Patch Dispense manual control, HOME/readiness handling and its HMI controls. Removed nest-support handling from the active station path to match the documented mechanical trial; retained compatibility interfaces and restoration comments require equipment review.
- Revised main-door lock supervision and its machine integration.
- Improved process settings editing and time-entry controls, Heat Stake settings presentation, statistics, system information and I/O status displays.
