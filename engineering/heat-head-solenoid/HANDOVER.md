## Implementation

Machine-private state retains the last commanded head direction between existing sequence/manual request pulses. Final published head UP/DOWN outputs are complementary and continuous. UP wins simultaneous requests. Actual Up/Down sensors still determine sequence progress and existing fault supervision; reaching either sensor does not drop the final valve command. Holding DOWN covers manual arrival, the request gap on automatic dwell entry and the full dwell; an UP request changes and retains direction.

An UP recovery latch starts TRUE. Machine Fault, aggregate safety loss, process-safety permission loss or loss of bAirSupplySafe sets it and clears held DOWN. It overrides DOWN requests in the final machine output arbitration, after state/fault handling and before the outputs are published. Safety restoration, ordinary Reset and entry into Initialising do not release it. Release requires the Initialising -> ReadyToStart transition with Head Up TRUE and Head Down FALSE, with the safety/air conditions still valid. The last direction remains UP after release until a new active DOWN request. No pre-fault held direction is replayed. The existing previous-state scan latch is used before its final update.

Terminal mapping now writes Term9 Ch7 from the final logical HeadUp output. Coil4 is always FALSE, Coil5 always TRUE, Coil3 Unlock unchanged. The existing Term9 Ch7 physical link was inspected, not edited. PRG_WriteOutputs continues copying final machine commands normally. Public DUTs/signatures, sensors, temperatures/protection thresholds, heat/pressure logic, TwinSAFE program and safety configuration are unchanged. This is standard PLC output arbitration; it does not establish a safety-rated retraction function or guarantee position with the PLC/task stopped or electrical/pneumatic energy unavailable.

Native IO card descriptions identify the new Term9 single-solenoid polarity, retired Coil4 and continuous Coil5 pilot. Read-only symbol bindings remain unchanged. Heat Stake manual sensor indicators still show physical feedback.
