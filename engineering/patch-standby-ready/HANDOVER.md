# Patch ReadyToStart indication — 2026-11-09

The station's bReady requires bDriveStandstillInternal, mapped from M1 Axis.Status.StandStill. The machine grants M1 bDrivePermit only in AutoCycle, enabled Manual and Stopping. ReadyToStart therefore leaves the motor intentionally disabled, which can explain Ready remaining false until AutoCycle. These source paths were inspected; the reported runtime state was not sampled in this task.

Only PRG_HmiStatus is changed. In ReadyToStart, the displayed station Ready now requires commissioned status, station enum Ready, confirmed Home, no station Busy or aggregate station/feed/M1 fault, machine safety/motion permission, closed door, safe air supply, no feed activity or actual M1 movement, no NC ErrorStop and a nonzero linked axis ID. M1 must report StandStill or Disabled. No enable command is issued. AutoCycle/Manual status projection, station FB IsReady, RequestStart, process/index gates, actuator commands, motor controls and protection behavior remain unchanged. This is a standby indication, not proof that M1 is powered or immediately able to move.

The dedicated check executes the actual new ST block, covers both standstill/disabled combinations, individually removes each prerequisite, injects fault/busy/movement conditions, checks linked/unlinked axis and station states, and preserves the original Ready in every other machine mode. Only the HMI Ready field is assigned. Exact before/after source scope and XAE/disk hash readback pass. PLC Release x64 build succeeded with zero failed projects and no source diagnostics; older runtime Error List entries remain separate. Existing IO/HMI mapping checks pass. The earlier patch-manual-status/check_status.py whole-page fixture fails because the saved designer layout was already moved relative to its historical baseline (e.g. UP label top 78 -> 88); that fixture and the layout were preserved. Its historical readback was not repurposed. The new test proves all code outside the appended standby block is unchanged, including Manual indication.
